# Auto Slot Machine

一个用于自动点击抽奖的浏览器篡改猴脚本。

## 功能

- 在页面右上角添加一个悬浮按钮
- 每 6 秒自动点击一次抽奖按钮
- 支持手动开启和关闭自动抽奖功能
- 适用于以下网站：
  - [KYX 娱乐站](https://quota.kyx03.de/)（已关闭）
  - [莹のapi 加油站](https://quota.wpgzs.top/)

## 安装

1. 安装浏览器用户脚本管理器扩展（如 Tampermonkey、Greasemonkey 等）
2. 将 `auto-slot-machine.js` 文件添加到用户脚本管理器中
3. 访问支持的网站，脚本会在右上角添加一个悬浮按钮

## 使用方法

- 点击右上角的蓝色悬浮按钮（▶️）开始自动抽奖
- 再次点击按钮（⏹️）停止自动抽奖
- 脚本启动后会立即执行一次抽奖，然后每6秒重复一次
